# AE CLOTHING — ملفات الموقع

## تشغيل الموقع
افتح `index.html` في المتصفح لمعاينة النسخة الأولية.

## الملفات
- `index.html`: بنية صفحات المتجر.
- `styles.css`: التصميم المتجاوب.
- `app.js`: البحث والسلة وإرسال الطلب عبر واتساب.

## إضافة منتج تجريبي
افتح أدوات المطور في المتصفح (F12) ثم Console واكتب:
```js
AEStore.addProduct({
  name: "AE Essential Tee",
  description: "وصف المنتج",
  price: 0,
  category: "tshirt",
  sizes: ["M", "L", "XL"]
});
```
استبدل السعر والسعر صفر مجرد مثال تقني، ولا تستخدمه كسعر بيع.

## تنبيه مهم
هذه نسخة Front-end أولية. المنتجات والسلة محفوظة محلياً في متصفح الزائر فقط. لا توجد قاعدة بيانات مركزية أو لوحة إدارة آمنة أو تسجيل مركزي للطلبات. قبل التشغيل التجاري الكامل، يلزم ربط Backend وقاعدة بيانات وتأمين صلاحيات الإدارة. لا تضع مفاتيح سرية داخل ملفات JavaScript العامة.

الطلبات الحالية تُرسل إلى واتساب، والدفع عند الاستلام. يجب تحديد رسوم الشحن وإبلاغ العميل بها قبل تأكيد الطلب.
